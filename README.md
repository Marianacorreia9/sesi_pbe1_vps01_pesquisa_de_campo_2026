# Pesquisa de Campo - Uso de Inteligência Artificial

## Tema

Pesquisa de campo sobre o uso de Inteligência Artificial por empresas, escolas e pessoas, identificando a finalidade de uso, a tecnologia utilizada, o nível de risco e a existência de revisão humana.

## Tecnologias utilizadas

- Node.js
- Express
- JavaScript
- JSON
- HTML
- Thunder Client
- GitHub
